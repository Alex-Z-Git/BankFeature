
# Набор скриптов для обработки банковских событий

### модуль masks 
получает номер счета или карты возвращает замаскированные номера карт и счетов

### модуль widget 
* принимает строки с номерами счетов и карт формата Visa Platinum 7000792289606361, 
или Счет 73654108430135874305 и возвращает Visa Platinum 7000 79** **** 6361 или
Счет **4305

* принимает на вход 
строку с датой в формате "2024-03-11T02:26:18.671407"
и возвращает строку с датой в формате "ДД.ММ.ГГГГ"  ("11.03.2024").

### модуль processing 
* содержит функцию сортирующая список по значению state ('EXECUTED' по умолчанию)
* содержит функция сортирующую список словарей по значению "date" и возвращающую 
новый отсортированный список. Направление сортировки задается параметром 'direction'
True (по умолчанию) - убывание, False - возрастание.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Alex-Z-Git/BankFeature.git
```
2. Установите зависимости:
```
poetry install
```
## Использование:

1. Откройте терминал и запустите в нем нужный модуль
```
python "widget.py" 
```
2. Используйте функционал модулей для Ваших задач
